Secure Sandboxing for Kubernetes

gVisor · Rootfs snapshots · Self‑hosted · Apache 2.0

Run untrusted and AI-generated code on your own Kubernetes cluster. Every sandbox is gVisor-isolated, snapshotable, and restorable on any node.

gVisor Isolation

Every sandbox runs behind gVisor's application kernel. Strong isolation in user space, no VMs required.

Rootfs Snapshots

Capture a sandbox's filesystem and restore it in new sandboxes on any node.

Self‑Hosted

One Helm install on your own cluster. You control the infrastructure and the data.

Open Source

Apache 2.0 licensed. REST API and Python SDK, built on Kubernetes primitives you already know.

Python 
from isola import Isola

with Isola() as client:
    sandbox = client.sandboxes.create(image="python:3.12-slim")

    result = sandbox.commands.run("python3", "-c", "print('hello from a sandbox')")
    print(result.stdout)  # "hello from a sandbox\n"

    # Snapshot the rootfs to restore it in new sandboxes on any node
    client.rootfs_snapshots.create(sandbox_id=sandbox.id, snapshot_name="demo")
