# Tutorial: AI Code Execution

Learn how to safely execute LLM-generated code in isolated sandboxes. This is the primary use case for Isola - running untrusted code from AI agents without risking your infrastructure.

---

## Overview

When building AI-powered applications, you often need to:

- Execute code generated by LLMs
- Run user-provided scripts safely
- Process outputs without security risks

Isola provides the isolation layer to do this safely.

## Step 1: Create a Secure Template

First, create a template optimized for AI code execution:

```yaml
# ai-execution-template.yaml
apiVersion: sandbox.isola.run/v1alpha1
kind: SandboxTemplate
metadata:
  name: ai-code-execution
  namespace: isola-sandboxes
spec:
  timeoutSeconds: 30  # Short timeout for code snippets
  podTemplate:
    spec:
      containers:
        - name: sandbox
          image: python:3.11-slim
          command: ["sleep", "infinity"]
          workingDir: /workspace
          env:
            - name: PYTHONDONTWRITEBYTECODE
              value: "1"
          resources:
            requests:
              cpu: "100m"
              memory: "128Mi"
            limits:
              cpu: "500m"
              memory: "256Mi"  # Limit memory for safety
```

Apply it:

```bash
kubectl apply -f ai-execution-template.yaml
```

**Security note:** This template has no network access (uses default `isola-isolated` network policy).

## Step 2: Create the Execution Service

Here's a complete Python service that executes LLM-generated code:

```python
# ai_executor.py
import json
import os
from dataclasses import dataclass
from typing import Optional
from isola_client import IsolaClient


@dataclass
class ExecutionResult:
    success: bool
    output: str
    error: Optional[str] = None
    exit_code: int = 0


class AICodeExecutor:
    """Safely execute LLM-generated code in isolated sandboxes."""

    def __init__(self, api_url: str, api_key: str):
        self.client = IsolaClient(api_url, api_key)
        self.template = "ai-code-execution"

    def execute_python(self, code: str, timeout: int = 30) -> ExecutionResult:
        """
        Execute Python code in an isolated sandbox.

        Args:
            code: Python code to execute
            timeout: Maximum execution time in seconds

        Returns:
            ExecutionResult with output, errors, and exit code
        """
        sandbox = None
        try:
            # 1. Create sandbox
            sandbox = self.client.create_sandbox(
                name=f"ai-exec-{os.urandom(4).hex()}",
                template_name=self.template,
                auto_start=True
            )

            # 2. Wait for ready
            sandbox = self.client.wait_for_state(
                sandbox['id'], "running", timeout=30
            )

            # 3. Upload the code
            self.client.upload_file(
                sandbox['id'],
                "/workspace/code.py",
                code.encode('utf-8')
            )

            # 4. Execute with timeout
            result = self.client.execute_command(
                sandbox['id'],
                "python /workspace/code.py",
                timeout=timeout
            )

            return ExecutionResult(
                success=result['exitCode'] == 0,
                output=result['stdout'],
                error=result['stderr'] if result['stderr'] else None,
                exit_code=result['exitCode']
            )

        except Exception as e:
            return ExecutionResult(
                success=False,
                output="",
                error=str(e),
                exit_code=-1
            )

        finally:
            # 5. Always cleanup
            if sandbox:
                try:
                    self.client.terminate_sandbox(sandbox['id'])
                except Exception:
                    pass  # Best effort cleanup


# Usage example
if __name__ == "__main__":
    executor = AICodeExecutor(
        api_url=os.environ.get("ISOLA_API", "http://localhost:8080"),
        api_key=os.environ.get("ISOLA_API_KEY", "iso_sk_demo")
    )

    # Simulate LLM-generated code
    llm_code = """
# Calculate Fibonacci sequence
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)

# Print first 10 numbers
for i in range(10):
    print(f"fib({i}) = {fib(i)}")
"""

    result = executor.execute_python(llm_code)

    if result.success:
        print("Output:")
        print(result.output)
    else:
        print(f"Error: {result.error}")
        print(f"Exit code: {result.exit_code}")
```

## Step 3: Integrate with Your LLM

Here's how to integrate with an LLM (using OpenAI as an example):

```python
# llm_integration.py
import openai
import os
from ai_executor import AICodeExecutor, ExecutionResult


class LLMCodeAssistant:
    """LLM assistant that can execute code safely."""

    def __init__(self):
        self.executor = AICodeExecutor(
            api_url=os.environ["ISOLA_API"],
            api_key=os.environ["ISOLA_API_KEY"]
        )
        self.openai = openai.OpenAI()

    def ask_and_execute(self, question: str) -> str:
        """
        Ask the LLM to generate code, then execute it.
        """
        # 1. Generate code with LLM
        response = self.openai.chat.completions.create(
            model="gpt-4",
            messages=[
                {
                    "role": "system",
                    "content": """You are a Python coding assistant.
                    When asked to solve a problem, respond with ONLY
                    executable Python code. No explanations, no markdown."""
                },
                {"role": "user", "content": question}
            ]
        )

        code = response.choices[0].message.content

        # 2. Execute in sandbox
        result = self.executor.execute_python(code)

        # 3. Return formatted result
        if result.success:
            return f"Code executed successfully:\n\n{result.output}"
        else:
            return f"Execution failed:\n{result.error}\n\nCode:\n{code}"


# Interactive demo
if __name__ == "__main__":
    assistant = LLMCodeAssistant()

    questions = [
        "Calculate the sum of prime numbers under 100",
        "Generate a random password with 16 characters",
        "Find the factorial of 10",
    ]

    for question in questions:
        print(f"\nQuestion: {question}")
        print("-" * 50)
        answer = assistant.ask_and_execute(question)
        print(answer)
```

## Step 4: Handle Edge Cases

### Timeout Protection

```python
def execute_with_retry(self, code: str, max_retries: int = 2) -> ExecutionResult:
    """Execute with retry logic for transient failures."""
    for attempt in range(max_retries):
        result = self.execute_python(code, timeout=30)

        if result.success:
            return result

        # Retry on timeout, but not on code errors
        if "timeout" not in str(result.error).lower():
            return result

        print(f"Attempt {attempt + 1} timed out, retrying...")

    return result
```

### Memory Limit Handling

```python
def execute_safe(self, code: str) -> ExecutionResult:
    """Execute with additional safety checks."""
    # Check for obvious memory bombs
    dangerous_patterns = [
        "while True",
        "[0] * 10**",
        "range(10**10)",
    ]

    for pattern in dangerous_patterns:
        if pattern in code:
            return ExecutionResult(
                success=False,
                output="",
                error=f"Potentially dangerous pattern detected: {pattern}"
            )

    return self.execute_python(code)
```

### Output Truncation

```python
def execute_with_limit(self, code: str, max_output: int = 10000) -> ExecutionResult:
    """Execute and truncate large outputs."""
    result = self.execute_python(code)

    if len(result.output) > max_output:
        result.output = result.output[:max_output] + "\n... (output truncated)"

    return result
```

## Step 5: Add Logging and Monitoring

```python
import logging
import time
from contextlib import contextmanager

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class MonitoredExecutor(AICodeExecutor):
    """Executor with logging and metrics."""

    @contextmanager
    def _timed_execution(self, operation: str):
        start = time.time()
        try:
            yield
        finally:
            duration = time.time() - start
            logger.info(f"{operation} completed in {duration:.2f}s")

    def execute_python(self, code: str, timeout: int = 30) -> ExecutionResult:
        logger.info(f"Executing code ({len(code)} bytes)")

        with self._timed_execution("Code execution"):
            result = super().execute_python(code, timeout)

        if result.success:
            logger.info(f"Success: {len(result.output)} bytes output")
        else:
            logger.warning(f"Failed: {result.error}")

        return result
```

## Complete Example: Code Playground API

Here's a complete FastAPI service for a code playground:

```python
# playground_api.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from ai_executor import AICodeExecutor
import os

app = FastAPI(title="Code Playground")

executor = AICodeExecutor(
    api_url=os.environ.get("ISOLA_API", "http://localhost:8080"),
    api_key=os.environ.get("ISOLA_API_KEY", "iso_sk_demo")
)


class CodeRequest(BaseModel):
    code: str
    timeout: int = 30


class CodeResponse(BaseModel):
    success: bool
    output: str
    error: str | None
    exit_code: int


@app.post("/execute", response_model=CodeResponse)
async def execute_code(request: CodeRequest):
    """Execute Python code in an isolated sandbox."""
    if len(request.code) > 100_000:
        raise HTTPException(400, "Code too large (max 100KB)")

    if request.timeout > 60:
        raise HTTPException(400, "Timeout too long (max 60s)")

    result = executor.execute_python(request.code, request.timeout)

    return CodeResponse(
        success=result.success,
        output=result.output,
        error=result.error,
        exit_code=result.exit_code
    )


@app.get("/health")
async def health():
    return {"status": "healthy"}


# Run with: uvicorn playground_api:app --reload
```

Test it:

```bash
curl -X POST http://localhost:8000/execute \
  -H "Content-Type: application/json" \
  -d '{"code": "print(sum(range(100)))"}'
```

## Security Best Practices

1. **Use isolated network** - Default template blocks all network access
2. **Set short timeouts** - 30 seconds is usually sufficient
3. **Limit resources** - 256Mi memory prevents most DoS
4. **Validate inputs** - Check code size and patterns
5. **Truncate outputs** - Prevent memory exhaustion from large outputs
6. **Always cleanup** - Use try/finally to terminate sandboxes
7. **Log everything** - Monitor for abuse patterns
