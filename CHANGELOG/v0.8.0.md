# v0.8.0

## Highlights

- **gVisor installer**: install and manage gVisor through Helm with `gvisor.installer.enabled=true`.
- **SDK filesystem API (breaking)**: separate text and byte read/write methods replace `read` and `write` in both SDKs. TypeScript's `UploadBody` type is now `BinaryBody`.
- **Reliability fixes**: improved rootfs snapshots and streaming.
- **Security and dependency updates**: refreshed Go, Kubernetes, SDK tooling, and GitHub Actions dependencies.

## Installing

```bash
kubectl create namespace isola-sandboxes
helm install isola oci://ghcr.io/isola-run/charts/isola \
  --namespace isola-system --create-namespace \
  --version 0.8.0
```

Python SDK:

```bash
pip install isola-run==0.8.0
```

TypeScript SDK:

```bash
npm install @isola-run/sdk@0.8.0
```

See the [README](../README.md), [Python SDK docs](../sdks/python/README.md), and [TypeScript SDK docs](../sdks/typescript/README.md) for deployment and API usage.
