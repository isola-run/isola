# v0.8.0

## Highlights

- **Automatic gVisor installation**: an opt-in Helm-managed DaemonSet installs and upgrades pinned gVisor releases on eligible nodes. The chart creates a RuntimeClass that schedules sandboxes only onto verified nodes, and retains older releases for running sandboxes.
- **Rootfs snapshot reliability**: snapshot jobs use the gVisor release each sandbox started with when the installer manages the runtime. Completed snapshot status is saved before job cleanup, and failed cleanup is retried.
- **Command and file streaming fixes**: interrupted streams report failures instead of silently returning truncated output, disconnected long-poll requests are handled cleanly, and large environment values no longer hide container identity during process lookup.
- **SDK fixes**: Python async command runs cancel outstanding output readers when a wait fails. TypeScript command deadlines now cover stdin writes, and snapshot creation timestamps are protected from caller mutation.
- **Docs and development**: redesigned the project website, moved local gVisor setup into the Helm installer, and restricted the development registry to localhost. The setup script now installs pinned development tools and supports `--tools-only`.
- **Security, dependency, and CI refresh**: updated core Kubernetes and Go dependencies, Python and TypeScript tooling, and GitHub Actions. The release workflow now publishes the gVisor installer image.

## Installing

```bash
kubectl create namespace isola-sandboxes
helm install isola oci://ghcr.io/isola-run/charts/isola \
  --namespace isola-system --create-namespace \
  --version 0.8.0
```

To install gVisor through the chart, add `--set gvisor.installer.enabled=true`. The privileged installer requires systemd-managed containerd using `/etc/containerd/config.toml` and writable host paths. It restarts containerd on eligible nodes. See [gVisor setup](../README.md#gvisor-setup) for details.

Python SDK:

```bash
pip install isola-run==0.8.0
```

TypeScript SDK:

```bash
npm install @isola-run/sdk@0.8.0
```

See the [README](../README.md), [Python SDK docs](../sdks/python/README.md), and [TypeScript SDK docs](../sdks/typescript/README.md) for deployment and API usage.
