# v0.7.0

## Highlights

- **Egress rate limiting**: cap sustained outbound bandwidth per sandbox with `network.egressRateLimitBytesPerSecond`, available through the CRD, REST API, Python SDK, and TypeScript SDK.
- **Security, dependency, and CI refresh**: refreshed core Kubernetes, Go, Python, TypeScript, testing, gVisor, and GitHub Actions dependencies, and removed the duplicate TypeScript SDK live e2e suite in favor of the project-level e2e suite.

## Installing

```bash
kubectl create namespace isola-sandboxes
helm install isola oci://ghcr.io/isola-run/charts/isola \
  --namespace isola-system --create-namespace \
  --version 0.7.0
```

Python SDK:

```bash
pip install isola-run==0.7.0
```

TypeScript SDK:

```bash
npm install @isola-run/sdk@0.7.0
```

See the [README](../README.md), [Python SDK docs](../sdks/python/README.md), and [TypeScript SDK docs](../sdks/typescript/README.md) for deployment and API usage.
