# v0.6.0-rc.1

> Release candidate published for verification. The v0.6.0 release will follow after RC validation.

Isola is a free and open-source Kubernetes sandbox platform for running untrusted and AI-generated code safely in existing clusters.
One Helm install deploys the whole system onto any cluster with gVisor configured.

## Highlights

- **TypeScript SDK**: first public release candidate of `@isola-run/sdk`, bringing first-class TypeScript and JavaScript support alongside the existing Python SDK.
- **Security and dependency refresh**: refreshed core Kubernetes, Go, Python, TypeScript, testing, and GitHub Actions dependencies.

## Installing

```bash
kubectl create namespace isola-sandboxes
helm install isola oci://ghcr.io/isola-run/charts/isola \
  --namespace isola-system --create-namespace \
  --version 0.6.0-rc.1
```

Python SDK:

```bash
pip install isola-run==0.6.0rc1
```

TypeScript SDK:

```bash
npm install @isola-run/sdk@0.6.0-rc.1
```

See the [README](../README.md), [Python SDK docs](../sdks/python/README.md), and [TypeScript SDK docs](../sdks/typescript/README.md) for deployment and API usage.
