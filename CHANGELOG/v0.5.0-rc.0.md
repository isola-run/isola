# v0.5.0-rc.0

Release date: 2026-04-18

First public release candidate of Isola.

## Added

- Kubernetes operator for sandbox lifecycle (Sandbox CRD).
- Sandbox sidecar for in-pod filesystem / command API.
- API gateway providing REST endpoints for SDK clients.
- Rootfs snapshot workflow (RootfsSnapshot CRD + snapshot-uploader + snapshot-mounter).
- Python SDK (`isola-run` on PyPI).
- Helm chart published to `oci://ghcr.io/isola-run/charts/isola`.
- Container images signed (cosign keyless OIDC) with attached SPDX SBOMs and GitHub build provenance.

## Known limitations

- Rootfs restore retry requires Kubernetes 1.34+ (`ContainerRestartRules` feature gate).
- Pre-1.0 — breaking changes to CRDs, REST API, and SDK are possible between releases.

## Install

```bash
# Helm (OCI)
helm install isola oci://ghcr.io/isola-run/charts/isola --version 0.5.0-rc.0

# Python SDK (RC — requires --pre)
pip install --pre isola-run==0.5.0rc0

# Raw manifests (GitOps / kubectl apply)
kubectl create namespace isola-system
kubectl apply -f https://github.com/isola-run/isola/releases/download/v0.5.0-rc.0/isola.crds.yaml
kubectl apply -f https://github.com/isola-run/isola/releases/download/v0.5.0-rc.0/isola.yaml
```
