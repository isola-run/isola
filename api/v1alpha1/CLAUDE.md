# api/v1alpha1/

Kubernetes CRD type definitions for the `sandbox.isola.run` API group.

## CRDs

- **Sandbox** (`sandbox_types.go`) — A running sandbox instance. Short name: `sb`
- **RootfsSnapshot** (`rootfssnapshot_types.go`) — Triggers a snapshot of a sandbox's container rootfs. Short name: `rfs`

## Key Conventions

- **Conditions, not phases.** Status uses K8s conditions (`Ready`, `PodReady`, `NetworkConfigured`, `TimedOut`, `SnapshottingFilesystem`), not the deprecated phase pattern.
- **Pointer booleans.** `NetworkSpec.AllowAllInternet` and `AllowClusterDNS` are `*bool` to distinguish unset from false.
- **Immutability.** `SandboxSpec.Network` is immutable after creation (enforced via CEL validation rules on the spec).
- **Kubebuilder markers.** Validation, defaults, and print columns are defined via `+kubebuilder:` comments. These drive CRD generation.

## After Modifying Types

```bash
make generate   # Regenerates zz_generated.deepcopy.go
make manifests  # Regenerates CRD YAML in charts/isola/crds/ and RBAC in charts/isola/generated/
```

Both commands must be run — `generate` updates DeepCopy methods, `manifests` updates the Helm chart CRDs and RBAC.
