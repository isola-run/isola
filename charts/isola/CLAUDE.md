# charts/isola/

Main Helm chart for deploying Isola. Requires Kubernetes >= 1.25.

## Directory Structure

```
charts/isola/
├── Chart.yaml              # Chart metadata (version 0.1.0)
├── values.yaml             # Default values
├── values-dev.yaml         # Development overrides (used with Tilt)
├── crds/                   # Generated CRD manifests (do not edit)
├── generated/              # Auto-generated RBAC rules (do not edit)
│   └── role.yaml           # Aggregated from kubebuilder annotations
└── templates/
    ├── _helpers.tpl         # Common Helm helper functions
    ├── NOTES.txt            # Post-install instructions
    ├── operator/            # Operator deployment and RBAC
    └── api-gateway/         # API gateway deployment and RBAC
```

## Generated Content (do not edit by hand)

- `crds/` — CRD YAML generated by `make manifests` (controller-gen)
- `generated/role.yaml` — RBAC rules generated by `make manifests` (controller-gen)

The operator's `clusterrole.yaml` template uses `.Files.Get` to include `generated/role.yaml` with proper Helm templating for name/labels.

## Template Organization

### `templates/operator/`
- Deployment, ServiceAccount, ClusterRole/Binding, Role/Binding
- `namespace-sandboxes.yaml` — Creates the `isola-sandboxes` namespace
- Static NetworkPolicies: `sandbox-default-deny`, `sandbox-allow-internet`, `sandbox-allow-cluster-dns`, `sandbox-ingress`
- `sandbox-sidecars-service.yaml` — Headless service for sidecar communication
- `rootfssnapshot-serviceaccount.yaml` — SA for uploader jobs
- `sandbox-credentials.yaml` — Cloud credential secrets

### `templates/api-gateway/`
- Deployment, ServiceAccount, ClusterRole/Binding
- `role-sandbox-pods.yaml` / `rolebinding-sandbox-pods.yaml` — Gateway's role in sandbox namespace
- `service.yaml` — Gateway Service (ClusterIP)

## Regenerating CRDs and RBAC

```bash
make manifests
```

CI runs `make check-manifests` to verify generated files are in sync.
